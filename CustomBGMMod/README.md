# CustomBGMMod (배경음악 교체 모드)

게임 실행 시 `H:\steam\steamapps\common\HANS\hwa` 폴더를 자동으로 감시하여, 해당 폴더에 넣은 음악 파일(`.ogg`, `.mp3`, `.wav`, `.flac`)을 게임 배경음악(BGM)으로 자동 재생하고 원본 BGM을 교체합니다.

## 폴더 위치
- **경로:** `H:\steam\steamapps\common\HANS\hwa`
- 게임 실행 시 모드가 폴더가 없으면 자동으로 생성합니다.

## 지원 확장자
- `.ogg` (추천)
- `.mp3`
- `.wav`
- `.flac`

## 단축키
- **[F10]** : 커스텀 BGM 일시정지 / 다시 재생 토글
- **[F11]** : 다음 곡으로 넘기기 (음악 파일이 여러 개일 경우)
- **[Page Up]** : 볼륨 +10%
- **[Page Down]** : 볼륨 -10%

## 동작 원리
1. 게임 시작 시 `hwa` 폴더가 없으면 자동 생성합니다.
2. `hwa` 폴더에 음악 파일이 발견되면 인게임 BGM(`BP_Hans.BackgroundMusic`, `Gameplay_MainElizarV.Music`)을 자동으로 무음 처리하고 외부 고음질 플레이어로 커스텀 음악을 재생합니다.
3. 폴더에 음악 파일이 없으면 원래 게임 기본 BGM이 정상 재생됩니다.
4. 게임이 종료되면 백그라운드 음악 플레이어도 자동으로 함께 종료됩니다.
