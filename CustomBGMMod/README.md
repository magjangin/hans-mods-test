# CustomBGMMod (커스텀 배경음악 전용 모드)

`H:\steam\steamapps\common\HANS\hwa` 폴더에 음악 파일(`.ogg`, `.mp3`, `.wav`, `.flac`)이 있으면, 게임 실행 시 **키 입력 없이 전자동으로 게임의 모든 순정 사운드(BGM + 모든 효과음/환경음)를 100% 완전 차단**하고 오직 커스텀 음악만 깨끗하게 무한 루프 재생합니다.

## 폴더 위치
- **경로:** `H:\steam\steamapps\common\HANS\hwa`
- 게임 실행 시 폴더가 없으면 모드가 즉시 자동 생성합니다.

## 동작 방식
- **완전 무간섭 전자동 동작 (키 입력 불필요)**
- `hwa` 폴더에 음악 파일이 발견되면:
  1. 게임 엔진의 마스터/음악/SFX 볼륨 채널을 0으로 설정
  2. 인게임의 모든 오디오 컴포넌트(배경음, 송풍기, 바람 효과음 등)를 100% 침묵 처리
  3. 백그라운드 고음질 플레이어로 커스텀 음악만 단독 재생
- 음악 파일이 없으면 게임 순정 사운드가 정상 출력됩니다.
- 게임 종료 시 백그라운드 음악 플레이어도 함께 자동 종료됩니다.
